# Dabro · Мониторинг

Telegram-бот для Linux-сервера. При запуске присылает LAN IPv4 в настроенную группу. В ней же предупреждает, когда температура Intel CPU достигает 50 °C. Повторное предупреждение возможно после охлаждения до 47 °C или ниже.

## Запуск

1. Создайте бота через [@BotFather](https://t.me/BotFather) и добавьте его в группу с правом отправлять сообщения.
2. Скопируйте `compose.override.example.yaml` в `compose.override.yaml` и заполните значения в `services.bot.environment`.
   - `BOT_TOKEN` — токен бота.
   - `GROUP_CHAT_ID` — отрицательный числовой ID группы.
   - `ALLOWED_USER_IDS` — числовые ID пользователей для доступа в личке через запятую. Пустое значение отключает личные ответы.
3. На сервере должна быть доступна существующая Docker-сеть `vpn-proxy` с HTTP-прокси `http://vpn-proxy:8080`. Проверьте сеть командой `docker network inspect vpn-proxy`.
4. Запустите сервисы.

   ```sh
   docker compose up -d --build
   docker compose logs -f bot collector
   ```

Если ID неизвестны, заполните токен, соберите образ и запустите утилиту до основного бота. Она получает обновления через настроенный прокси и выводит ID при команде `/start` в личке или `/start@имя_бота` в группе. Остановите утилиту через Ctrl+C, внесите ID в Compose и запустите основной стек.

```sh
docker compose build bot
docker compose run --rm --no-deps bot python -m dabro_monitor.bot discover-ids
```

Пороги температуры, интервал замеров, время ожидания IP при запуске и адрес прокси заданы в `compose.yaml`. Если у сервера несколько интерфейсов, задайте `LAN_INTERFACE` для `collector`. По умолчанию он берёт адрес с интерфейса основного IPv4-маршрута.

## Команды

| Команда | Ответ |
| --- | --- |
| `/status` | Температура и загрузка CPU, RAM и аптайм сервера |
| `/ip` | LAN IPv4 |
| `/start`, `/help` | Список команд |

При включённой приватности Telegram используйте в группе `/status@имя_бота` и `/ip@имя_бота`. Данные группы доступны её участникам.

## Проверка на сервере

- Сверьте IP из стартового сообщения с `ip -4 addr`.
- Сверьте температуру с показаниями `sensors`, если утилита установлена. При недоступном датчике CPU бот показывает «нет данных», а остальные метрики обновляются.
- Запустите команды в настроенной группе и в личке разрешённого пользователя.
